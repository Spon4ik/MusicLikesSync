# v0.1 Safe Matching And Dry-Run Plan

## Goal

Stop weak Spotify search matches from being written into Spotify Liked Songs.

## Scope

- Add a pure matching module with tests.
- Integrate it into the existing script through a compatibility adapter.
- Keep live Spotify writes disabled by default.
- Add offline QA against cached search results.

## Acceptance Criteria

- Wrong-artist matches are rejected even when titles match.
- Duration mismatches are rejected when both sides expose duration.
- Featured artists can move between title and artist fields.
- Same ISRC is selected even when text metadata differs.
- Ambiguous candidates require review.
- Existing script compiles.
- Offline dry-run produces a review artifact and does not call Spotify.

## Commands

- `python -m unittest discover -s tests -v`
- `python -m py_compile "merge youtube Music likes into Spotify.py" music_likes_sync\matching.py music_likes_sync\legacy.py music_likes_sync\review.py`
- `python -m music_likes_sync.review data\search_results.json --output data\dry_run_match_review.json`
